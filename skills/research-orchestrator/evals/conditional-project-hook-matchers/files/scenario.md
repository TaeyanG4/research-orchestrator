# Project hook registrations

Use a disposable project with agents.md containing a Project settings section, Autonomy: present, and Brief requirements: none. Install project hooks for Claude Code with a disposable home. Record the tool matchers. Then change Autonomy to away and Brief requirements to reviewer: Inspect evidence, rerun the project installer, and record the updated matchers. Keep both settings snapshots for comparison. The generic plugin cannot know which project it will be used in; inspect its shipped declarations separately.

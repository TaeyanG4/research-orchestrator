# Disposable probe-path checks

Use the installed runtime's hooks/ or the shipped checkout wrappers. Record the wrapper paths and hashes so the observations can be tied to the code under test. A staged skill subtree without hooks/ is unavailable coverage, not a reason to recreate the wrapper. Save the harness and exact shell executables used.

For deterministic path checks, source the unmodified shell wrapper with an instrumented file-test builtin or use shell tracing to capture every file-probe operand. A cd shim may inject physical PWD spellings that Git would otherwise normalize; label those rows as simulated. Alternatively execute the actual join helper extracted unchanged from the wrapper, recording its inputs and outputs. Source inspection or a separately reimplemented join does not establish the observed result.

Cover a local POSIX descendant, the POSIX root, a drive-letter descendant, a bare drive designator and a drive root. Derive the drive letter from the temporary directory. Include roots and descendants with trailing separators, using both host project-directory variables and both Windows slash styles where the wrapper accepts them. Record all probe operands before any filtering. No local case should generate a // prefix, and the POSIX root marker probe should be exactly /agents.md. A drive root should have a single separator before agents.md. This catches a fast cached network lookup that a timing check alone would miss.

Add simulated UNC share roots and descendants, with and without trailing separators. Preserve the server/share prefix and stop the ancestor walk at the share. Use intercepted file tests or helper-only execution for these controls, so no network lookup is needed. For CMD, also test the actual join behavior at a drive root, a single-backslash root, a UNC share, and an extended-length Windows drive prefix. Check marker, directory and parent probe operands: local joins should not introduce a UNC or device prefix, an existing extended prefix should survive, and a trailing separator should not be doubled. Native CMD tracing or unchanged helper execution can establish this; clearly mark CMD unavailable on platforms without it.

Measure native shell and native CMD wrappers where available, outside instrumentation, from two fresh unrelated temporary directories whose ancestors have no agents.md. Clear inherited CLAUDE_PROJECT_DIR, CODEX_PROJECT_DIR, RO_HOOK_PYTHON, PWD and shell startup-file variables, then run each host hint independently with its Windows-style absolute directory. Use an empty PATH, no configured interpreter, and a newline-terminated JSON payload. Time each subprocess from launch through exit with a monotonic clock and a one-second timeout; each call should return JSON {}, exit zero and finish in less than one second. Record individual samples and timeouts rather than hiding them in an average. Harness creation is outside this measurement.

Finally create a private project with agents.md above two nested directories. With a harmless interpreter sentinel, exercise both host hints and both accepted slash styles from an unrelated cwd. Capture invocation count, cwd and stdin: ancestor discovery should dispatch once with the original cwd and payload. This positive control rejects a wrapper that achieves low latency by skipping discovery. State which results were native, simulated or helper-only, and keep unavailable coverage out of passing totals.

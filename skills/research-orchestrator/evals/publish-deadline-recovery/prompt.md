A publication scan timed out on a clean history. Show how to recover without disabling scanning. In a disposable project, create a Git repository with two small clean commits and configure Publish scan: secrets. Run the unchanged deadline_replay.py against that project and the installed skill's scripts directory; it injects a clock advance only inside this local process to reproduce the timeout. Save its report, apply the exact deadline setting named by the refusal while preserving the secret policy, then run a normal outgoing scan of HEAD versus HEAD~1 and record its result in recovery.md. Do not push, contact a remote, or modify the installed skill. Distinguish the simulated timeout from the normal scan result.

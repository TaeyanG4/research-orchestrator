Our publication gate stopped launching after Python was upgraded. Use the scenario in recovery.txt to verify the dispatcher locally with mocked process launches. Write recovery.json with the selected interpreter and final exit code for each scenario, including preservation of the exact Git input bytes. Do not push, invoke an agent host, or weaken the scan policy.

Use recovery.json keys override, python3, python, py, unavailable and denied. Each row has selected_command (an argv array, empty if unavailable), exit_code, stderr and scanner_calls. Each scanner call records stdin_hex and remote. Also record refs_hex and remote at the document root, plus override_command (the expected synthetic override argv).

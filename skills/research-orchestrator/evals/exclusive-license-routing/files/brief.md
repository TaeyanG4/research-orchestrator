# Layout export

The next unfinished goal is to export the approved handbook layout to a PDF for review. A desktop design application has one floating licensed seat shared with another worker using a different checkout. The export is a local CPU task with no GPU requirement; no machine is short of compute. The other worker may need the same seat at the same time, so access must be exclusive.

Setup answers: user operator, platform Codex, environment linux/bash, language en, Git off. Use work-project with its default queue ordering. The seat has no reservation service configured yet. Do not open the design app or run an export in this setup task.

Set up Research Orchestrator in disposable homes and Git projects using the supplied scenarios. Install both hosts, then remove one host in each project. Prove that the remaining publication gate still invokes its runtime by giving it malformed pre-push input. Include a project directory containing a dollar sign, apostrophe and backtick so the saved hook commands exercise literal path handling. Keep all actions inside the sandbox.

Install the optional CLI shim in the disposable home, invoke its help, then capture a SessionStart brief and invoke the exact command prefix it gives with `--help`. Save `audit.json` using the supplied schema, plus `shim-help.txt`, `prefix-help.txt` and `portability.md`. In the portability note explain which host configuration can be committed for reuse at another checkout path, and what to do for the other host. Keep your real home unchanged.

Input files: scenarios.json

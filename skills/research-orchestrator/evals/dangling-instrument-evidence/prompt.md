Audit the evidence checker for the attached measurement scenarios in a scratch research project. Register the valid instrument and supporting discoveries, then run each scenario in an isolated copy so findings can be attributed correctly. Capture the checker output and preserve each input ledger. Include both light and strict guards; also run historical, guards-off, and declared-inapplicable controls. Save a results.md listing actual check IDs, severity and cited record/field for each run. Do not change the skill implementation or replace missing evidence with invented records.

Input files: scenarios.txt, supporting-evidence.md
